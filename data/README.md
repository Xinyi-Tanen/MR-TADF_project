# Input data

| File | Purpose |
| --- | --- |
| `tadf_dataset.xlsx` | Training table used by the six property models and molecule generator |
| `core-structure info.xlsx` | Core labels and core SMILES definitions |
| `test molecules.xlsx` | External-validation table |

The scripts use the original spreadsheet column names. Do not reorder rows when
reproducing fixed data splits or reported results.

Confirm redistribution permission and source attribution for these files before
making the repository public.
